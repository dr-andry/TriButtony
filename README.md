Проект "Деда Штопорыча"

1. Есть папка modules - основные модули, которые будут использоваться в решении
2. Есть модуль ImageVectorDB - модуль для подключения к qdrant. Но, qdrant сначала надо запустить. Для этого качаем образ докер-контейнера (docker pull qdrant/qdrant) и запускаем

Сейчас как работает:
1. берётся фотка и через YOLO вырезается бутылка
2. Если бутылка на фотке есть - полученный кроп векторизуется.
3. Эмбеддинг дальше отправляется в qdrant
